# 2026-08-13 学习日志

## 知识点
- [AI/RAG] GraphRAG 的 Leiden 社区检测算法三阶段（local move / refinement / aggregation）→ 详见 [graphrag-leiden](/topics/ai/rag/graphrag-leiden)
- [AI/RAG] GraphRAG 实体与关系分离存储：实体存 `entities` 表，关系存 `relationships` 表（`source`/`target` 存实体名 title），查询时按 title join 成图

## 问题与解决
- **问题**: GraphRAG 抽出来的实体 JSON 只有 `title/description/degree`，没有关系字段，怎么知道"刘备和关羽什么关系"？
- **解决**: 关系是独立的边记录，存 `relationships` 表，`source`/`target` 用实体 `title` 字符串关联。Local Search 时向量匹配入口实体 → 按 title 拉 1-hop 邻居边 → 拼 prompt 生成答案。

## 今日总结
深入理解了 GraphRAG 的社区检测核心：Leiden 算法。local move（贪心跳槽聚小圈子）→ refinement（拆掉不连通假社区，Leiden 修 Louvain 的 bug）→ aggregation（压缩成超节点）三阶段循环，每轮图粗一层，产出 level 0/1/2 分层社区。
